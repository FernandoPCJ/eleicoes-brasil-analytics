# Eleições Brasil Analytics 🇧🇷

Projeto de Engenharia de Dados e Business Intelligence desenvolvido para análise do cenário eleitoral brasileiro utilizando dados públicos disponibilizados pelo Tribunal Superior Eleitoral (TSE).

## Objetivo

Construir um pipeline completo de dados eleitorais, desde a extração e tratamento dos dados até a disponibilização de análises estratégicas através de dashboards interativos no Power BI.

## Arquitetura do Projeto
Dados Públicos TSE
|
↓
Processamento ETL (Python)
|
↓
Banco de Dados PostgreSQL
|
↓
Power BI Dashboard

## Tecnologias utilizadas

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- Git/GitHub
